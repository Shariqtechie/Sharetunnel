How to get back in
  1. Open ShareTunnel's data folder (the one mounted at /data; on CasaOS: Files, then AppData, sharetunnel, data) and delete the file auth.json.
  2. Reload this page and create a new password.
Your settings and shared links are not touched. Or run this on the server to get a new random password:
docker exec sharetunnel sharetunnel reset-password
This password is set by the PANEL_PASSWORD setting. Change it there and recreate the container.
